# Intrinsic Motivation & Curiosity-Driven RL

## What It Is

Intrinsic motivation refers to reward signals generated by the agent itself, independent of any task-specific ("extrinsic") reward provided by the environment designer. The goal is to incentivize *exploration* — visiting novel states or learning accurate world models — so that the agent can acquire broadly useful skills even in the absence of task rewards.

In developmental psychology, intrinsic motivation (curiosity) is considered the primary driver of early skill acquisition in infants: children explore goal-free before they are given explicit tasks. Curiosity-driven RL operationalizes this idea computationally.

## Main Families of Intrinsic Reward

### 1. Prediction-Error / Dynamics-Based Curiosity

Reward the agent for transitions that are *hard to predict* with the current world model. Given encoder $\phi$, forward dynamics model $f$, transition $(x_t, a_t, x_{t+1})$:

$$r_t^\text{int} = \| f(\phi(x_t), a_t) - \phi(x_{t+1}) \|_2^2$$

The agent is rewarded for visiting states where its model is wrong — i.e., regions it has not yet understood. Key design question: **which feature space $\phi$ to use?**

| Feature space | Stable | Compact | Sufficient |
|--------------|--------|---------|------------|
| Raw pixels | Yes | No | Yes |
| Random Features (RF) | Yes | Yes | Maybe |
| Inverse Dynamics Features (IDF) | No | Yes | Maybe |
| VAE latents | No | Yes | Yes |

Burda et al. (2018) show RF is surprisingly competitive on in-distribution tasks, while IDF generalizes better to novel visual environments. See [[burda_2018_curiosity_largescale]].

**Key instantiations:**
- **ICM (Pathak et al. 2017):** Curiosity-Driven Exploration by Self-Supervised Prediction — uses IDF as the feature space; foundational paper introducing dynamics-based curiosity.
- **Large-Scale Curiosity (Burda et al. 2018):** First large-scale study across 54 environments with pure curiosity (no extrinsic reward).
- **RND (Burda et al. 2019):** Random Network Distillation — uses prediction error of a *fixed random target network* as intrinsic reward. Sidesteps the noisy-TV problem because the target is deterministic (no stochastic attractors).

### 2. Count-Based Exploration

Reward states that have been visited fewer times. For tabular MDPs, state visit counts $N(s)$ directly give a bonus $r^\text{int}(s) \propto 1/\sqrt{N(s)}$. For high-dimensional continuous spaces, pseudo-counts are derived from density models:

$$r^\text{int}(s) \propto \hat{n}(s)^{-1/2}$$

where $\hat{n}(s)$ is a pseudo-count from a density model (Bellemare et al. 2016). Count-based methods have shown strong results combined with extrinsic rewards (e.g., Montezuma's Revenge SOTA) but are less straightforward to scale and parallelize than dynamics-based methods.

### 3. Information-Theoretic / Empowerment

- **VIME (Houthooft et al. 2016):** reward is the information gain (KL divergence) of the agent's belief over dynamics model parameters — measures how much the agent *learned* from the transition.
- **Empowerment (Gregor et al. 2017):** reward is the mutual information between actions and future states — measures how much *control* the agent has over the environment.

## The Noisy-TV Problem

A fundamental limitation of prediction-error curiosity: any **stochastic element** in the environment (a TV showing random channels, partially observable noise, random opponents) generates high prediction error even with a perfect model. The agent becomes transfixed by the entropy source and stops exploring productively.

**Formal statement:** If transitions in the environment are truly random, even a perfect dynamics model has expected reward equal to the entropy of the transition. The agent seeks transitions with the highest entropy — irrelevant to task progress.

**Partial observability** and **poor model class** can produce the same effect. RND (fixed target network) avoids this because the target is a deterministic function of the observation — no irreducible noise.

## Practical Considerations for Pure Curiosity Training

From Burda et al. (2018):
- Use PPO as base RL algorithm (robust, minimal tuning).
- Normalize rewards and advantages within each batch.
- Use 128+ parallel actors for stability; 2048 for Mario-scale exploration.
- Batch-normalize the feature embedding.
- Remove the episode `done` signal (infinite horizon) to avoid extrinsic leakage.
- Feature dimension of 512 works well across Atari-scale environments.

## Relation to Self-Supervised Learning

Prediction-error curiosity is structurally similar to JEPA-style SSL: both train a forward dynamics model in a learned feature space and use prediction error as the learning signal. The key difference is the goal:
- **SSL (JEPA):** minimize prediction error to learn good representations — prediction error is the *training loss*.
- **Curiosity:** *maximize* prediction error as an exploration bonus — prediction error is the *reward*.

This dual relationship means insights about good feature spaces for SSL (compact, sufficient, stable) directly transfer to curiosity-driven RL. See [[joint-embedding-predictive-architecture]].
